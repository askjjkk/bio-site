## 💎 Особенности

* **Дизайн и адаптив:** Глубокий темный фон (`#050505`), полупрозрачные стеклянные карточки (`backdrop-filter`), плавные анимации при скролле (`IntersectionObserver`) и адаптивность под любые экраны (десктоп, мобильные).
* **🔊 Интерактивный плеер:** Кастомный медиаплеер с крутящейся виниловой обложкой и треком *«cupsize — ванна, красный пол»*, играющим прямо на сайте.
* **💡 О себе & Tech Stack:** Краткая информация (`System.Info`) и список используемых технологий (`Python`, `Java`, `JavaScript`, `HTML/CSS`, `C#`).
* **📁 Проекты:** Витрина работ (*TG Security Header Auditor Bot*, *Cyber Portfolio*) и прямая ссылка на Telegram-канал.
* **🚀 Контакты:** Удобный блок со всеми ссылками (Telegram, GitHub, анонимка, донаты).
* **⚡ Технологическая часть:** Написан на чистых HTML, CSS и Vanilla JS без тяжелых фреймворков — работает мгновенно и весит минимум.

---

## 🛠 Технологии

* **HTML5 / CSS3:** Flexbox, CSS Grid, Custom CSS Variables, Glassmorphism design system.
* **Vanilla JS:** Управление встроенным аудио-плеером (`Web Audio API`), анимации появления контента через `IntersectionObserver`, адаптивное мобильное меню.
* **Icons:** FontAwesome 6.x.
